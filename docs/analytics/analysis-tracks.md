# Query Library

Choose a question from a [business process](../learn-the-business/process-flows.md), then search by topic or source table below. Each query shows its objective, output grain, and main tables. **Show SQL** opens the logic for copying; **Download SQL** saves the original file.

For a first query, start with the [SQL Guide](sql-guide.md). Keep the assigned release unchanged and record the period, source population, and filters behind every result. The [reports](index.md) show finished outputs; the [cases](cases/index.md) define structured investigations.
