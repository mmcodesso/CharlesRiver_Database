# Report selection refinement

## Result

The report catalog no longer repeats the source-SQL action; the link remains inside each opened report. The report viewer has no Print button. Original PDF/Excel actions, original CSV URLs, source SQL destinations and established report routes are retained.

Every retained report was reviewed for grain, period basis and useful dimensions. The collection now contains 25 core and 28 specialist reports. The five previously retired entries remain retired. The per-report decisions and complete 170-query inventory are in `AUDIT.md`.

Monthly Revenue and Gross Margin opens with a year of monthly rows. Suitable time-series reports support selected period, previous period, year by period, previous year by period, and all periods. Multi-period tables explicitly identify each row's period; they do not invent annual sums or average percentages. Annual statements offer selected year, previous year and all-year comparisons. Aging reports permit selected-snapshot and prior-snapshot views and suppress totals across repeated snapshots. Whole-file/cumulative reports retain their source scope rather than acquiring misleading date cutoffs.

Filter options cascade using the other selected dimensions and search text. One-choice controls are hidden unless selected, and unavailable selections remain visible with an explanation and an empty result. Added dimensions include supplier category/risk, payroll class and job level, employment status, product/style/material/lifecycle, commission rep/type, account name and document/approval assignments, wherever supported by source fields. Punch to Pay now uses actual payroll-period end dates. URL sharing, Back/Forward, pagination, keyboard controls and empty states remain supported.

## Additional reports

The existing canonical queries supply ten new views: monthly direct cash flow; annual income statement, balance sheet, direct cash flow and indirect cash flow; trial balance; fixed-asset rollforward; debt amortization/cash impact; monthly work-order throughput; and Design Services engagement utilization/labor margin. Quarterly SQL remains in the Query Library. Detailed inventory movement remains a query rather than adding a large additional report snapshot.

The new website-only catalog is `src/data/additionalReports.json`, combined with the original generated report manifest by the viewer registry. No frozen generator catalog or generated report manifest was hand-edited. Report topics and teaching metadata include the new IDs once each, aligned with their existing query topics.

`scripts/prepare-additional-report-snapshots.py --write` deliberately authors only the ten small website JSON snapshots under `static/report-snapshots/` and their new private verification register. It verifies the teaching database checksum and executes unchanged queries with SQLite `mode=ro`. Total snapshot size is 1,020,537 bytes. Running the command without `--write` verifies the snapshots against the database without changing them. The normal website preparation validates their snapshot and normalized query hashes, then creates ignored period partitions and routes in both local and CI builds. LF attributes keep snapshot hashes stable across platforms.

These presentation snapshots are separate from the protected report Excel/CSV/preview outputs. For the original 43 reports, Export Data retains its existing CSV destination. New reports export complete verified snapshot rows to CSV in the browser; their PDF/Excel exports follow the selected view. No existing dataset, download or report asset is regenerated or overwritten, and no new dependency is introduced.
