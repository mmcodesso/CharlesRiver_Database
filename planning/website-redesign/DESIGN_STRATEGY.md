Primary navigation groups learning resources without crowding the header; downloads and instructors remain direct. Add `/docs/learn-and-practice` only; do not rename SQL, report, or case files.

## Visual system

Use Hub-compatible paper `#faf9f5`, ink/navy `#152b35`, teal `#196252`, sage `#e9efea`, thin borders, modest corners and editorial serif headings. Use system font stacks to eliminate the existing render-blocking remote font request and avoid dependencies. Homepage: concise environment label, company-led headline preserving business-before-joins principle, direct actions for company/learning/downloads/instructors, a linked process-to-ledger visual, verified release specifications, three course entry paths, selected existing cases, and Hub/textbook relationship. ## Editorial and learning model

Company profile separates established synthetic operating model from illustrative narrative. A typical cycle explains commitments, recognition, collection, supply, labor and close without asserting every event automatically posts. Process pages retain accounting nuance and analytical bridges.

Activities expose level, process/accounting area, prerequisites, tools, objectives, source documents/tables, workflow, assessed deliverable and interpretation limits. The case catalog is curated website source, separate from canonical SQL/generated manifests; all 17 existing cases appear in initial HTML, filters progressively narrow them, and reset/empty-result/status behavior is accessible. Do not expose assignment solutions. Existing query/report references remain authoritative.

Keep canonical production origin, local search and generated sitemap. Unique title/description per page; one H1, semantic headings, ordinary crawlable links. Stable Dataset graph with real release metadata; LearningResource data for visible activities; existing BreadcrumbList retained. Link to primary Hub and textbook resources and canonical GitHub release/repository. Claims describe the inspected v2027.1 release; 82-table count is established by its checksum-matched database, not generator assumptions.
